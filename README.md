A colossal luminous whale breaches out of a sea of stars — painted
procedurally, pixel by pixel, by `main.ts` (Node 22, standard library
only). No image files, no network, no randomness: every run produces
the exact same PNG.

## Run

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts   # writes out/entry.png
```

The image is 1024×1024 PNG, well under 1 MiB, deterministic across runs.
